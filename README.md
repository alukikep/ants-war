# 融合蚁大战 (Ant Colony Tug-of-War)

一款策略性拔河游戏，玩家通过建造孵化室、组装不同部件的蚂蚁来对抗 AI 敌人。

> 架构、运行入口、模块接口与扩展开发请参考 [ARCHITECTURE_AND_INTERFACES.md](ARCHITECTURE_AND_INTERFACES.md)。

## 游戏玩法

### 核心机制
- **双方对抗**: 玩家（蓝方）在左侧，AI（红方）在右侧，各有一个蚁后基地
- **孵化室建造**: 在蚁后后方的建造区域放置孵化室，消耗食物
- **自动生产**: 每个孵化室定期孵化蚂蚁（初始10秒，每分钟+1秒，每室1只存活蚂蚁）
- **拔河战斗**: 蚂蚁自动向敌方基地前进，遭遇敌人时进行战斗
- **拔河优势**: 有单位越过中线时，每次食物生成额外+3
- **胜负条件**: 攻击对方蚁后使其血量归零即可获胜
- **蚁后反击**: 双方蚁后会主动攻击 350px 内靠近的敌方蚂蚁（每 0.5s 一发，50 伤害的蓝色/红色能量弹）
- **游戏速度**: 支持 1x / 2x / 3x 倍速切换（顶部右上角按钮）
- **难度选择**: 开局可在 普通 / 困难 / 极限 三档难度中选择（AI 获得的食物加成不同）

### 资源系统
- **初始食物**: 0（从零开始积攒）
- **食物生成**: 每2秒双方各获得食物，初始5，每过1分钟+1
- **拔河优势**: 有己方单位越过中线时，每次食物额外+3
- **难度食物加成**: 困难 +6 / 极限 +12（仅敌方食物每周期额外加，公平对战）
- **建造成本**: 基础60食物 + 部件成本
- **升级成本**: 等同于建造成本
- **拆除返还**: 50% 已投资资源

### 部件解锁系统
- **初始部件**: 双方各拥有基础三件套 + 随机1个阶段一部件（双方独立随机）
- **解锁频率**: 每过1分钟（游戏时间）双方各随机解锁一个部件
- **阶段限制**: 只能从已开放阶段中解锁，当前阶段全部解锁后需等待下一阶段开放

| 阶段 | 开放时间 | 可解锁部件 |
|------|---------|-----------|
| 阶段一 | 从开局起 | 火蚁头、木蚁胸、陷阱蚁腹、木蚁腹（共4个） |
| 阶段二 | 5分钟后 | 切叶蚁头、兵蚁头、行军蚁胸、子弹蚁胸、蜜罐蚁腹、织叶蚁腹（共6个） |
| 阶段三 | 10分钟后 | 大齿猛蚁头、白蚁大兵头、大头蚁头、切叶蚁胸、马塔贝勒蚁腹（共5个） |

### 科学家"实验性干预"系统

游戏过程中会有"科学家观察员"对战场进行暗中干预，每隔约 60–90 秒触发一次实验：

| 实验类型 | 效果 | 持续范围 |
|---------|------|----------|
| 🍯 食物注入 | 指定一侧食物产出倍率 ×1.3–×1.8 | 10–25s |
| 🥀 食物短缺 | 指定一侧食物产出倍率 ×0.5–×0.8 | 10–20s |
| 🧪 酸液场地 | 在指定一侧基地前方生成酸液毒场（120px 半径） | 8–15s |
| 🥚 孵化加速 | 指定一侧孵化室冷却 / 1.5–2.0 倍 | 10–20s |
| 🧊 孵化抑制 | 指定一侧孵化室冷却 ×0.5–×0.7 | 10–20s |
| 👑 蚁后亢奋 | 指定蚁后攻击冷却 / 1.3–1.8 倍 | 8–15s |
| 🌫️ 信号干扰 | 双方索敌范围临时 ×0.4–×0.7 | 5–12s |

- 实验由 **LLM 战略顾问** 决策（每 ~60s 调一次），未配置 LLM 时由 **离线启发式** 兜底
- 实验 **side 强制轮换**，玩家血低时禁止对其施加负面实验，保证基本公平
- 顶部居中横幅（ExperimentBanner）显示当前生效实验与剩余时间

## 孵化室系统

### 建造与管理

| 操作 | 说明 |
|------|------|
| 🏗️ 建造 | 点击空格，使用当前蚂蚁配置建造1级孵化室 |
| ⬆️ 升级 | 点击已有孵化室，花费建造成本升级 |
| 🗑️ 拆除 | 点击已有孵化室，拆除并返还50%资源 |

### 等级系统

| 等级 | 外观 | 属性加成 | 累计投资 |
|------|------|----------|----------|
| 1级 | 蓝色边框 | 基础属性 | 1x 成本 |
| 2级 | 金色边框 ★★ | +30% 攻击/生命（速度攻速不变） | 2x 成本 |
| 3级 | 紫色边框 ★★★ | +60% 攻击/生命（速度攻速不变） | 3x 成本 |

### 蚂蚁上限
- 每个孵化室最多同时拥有 **1只存活蚂蚁**
- 蚂蚁存活时，孵化室暂停生产
- 蚂蚁死亡后自动恢复孵化

## 战斗系统

### 蚂蚁行为状态

| 状态 | 行为 |
|------|------|
| **moving** | 向敌方基地前进，同时向中线靠拢 |
| **chasing** | 索敌范围(120px)内检测到敌人，追击目标 |
| **fighting** | 近战攻击范围(25px)内进入战斗，互相攻击 |
| **shooting** | 远程蚂蚁在射程(150px)内停止移动，发射酸液子弹 |

### 战斗特性
- **索敌追踪**: 蚂蚁会主动转向追击附近敌人
- **平滑旋转**: 蚂蚁身体朝向移动方向
- **2D战斗**: 蚂蚁在X/Y轴都会移动，形成自然战线
- **远程攻击**: 木蚁腹蚂蚁发射椭圆形酸液子弹，无法近战

### 切叶蚁头特性（暴击）

切叶蚁头拥有按孵化室等级递增的暴击几率：

| 孵化室等级 | 暴击几率 | 暴击伤害 |
|----------|---------|---------|
| 1级 | 5% | 3 倍伤害 |
| 2级 | 10% | 3 倍伤害 |
| 3级 | 15% | 3 倍伤害 |

- 暴击与切叶蚁胸的护甲、嘲讽机制完全兼容
- 暴击无视目标的护甲减伤（按原始基础伤害计算后 ×3）

### 子弹蚁胸特性（肾上腺素）

子弹蚁胸是高速突击型胸部部件，首次受到敌人攻击时自动触发肾上腺素：

| 孵化室等级 | 攻击力加成 | 护甲加成 | 持续时间 |
|----------|----------|---------|---------|
| 1级 | +50% | +50% | 5 秒 |
| 2级 | +75% | +60% | 8 秒 |
| 3级 | +100% | +80% | 12 秒 |

- 触发后进入 **60 秒冷却**，期间不会再次触发
- 护甲加成与嘲讽护甲叠加生效
- 适合配合高速移动 + 高攻速头部（如火蚁头）打一波爆发

### 木蚁胸特性（固定护甲）

木蚁胸拥有"固定护甲"机制，是一种简单可靠的减伤属性，护甲值随孵化室等级提升：

| 属性 | 说明 |
|------|------|
| 固定护甲 | **按孵化室等级：1级+5 / 2级+8 / 3级+12**（受到 X 伤害时实际只受 max(1, X − 护甲) 伤害） |
| 血量加成 | +15 |
| 速度加成 | +10 |
| 成本 | 60 食物 |

#### 护甲等级（根据孵化室等级）

| 等级 | 固定护甲 |
|------|----------|
| 1级 | **+5** |
| 2级 | **+8** |
| 3级 | **+12** |

**与百分比护甲的区别**：
- 固定护甲先于百分比护甲计算（先扣护甲值，再 ×(1 − 护甲%)）
- 对近战和远程伤害均生效
- 适合作为前排肉盾的基础配置
- 升级孵化室可显著提升木蚁胸的护甲值

**策略建议**：
- 与切叶蚁胸的百分比护甲叠加 → 高效坦克
- 推荐配置：兵蚁头 + 木蚁胸 + 蜜罐蚁腹（高血量 + 固定护甲 + 死亡回复）

### 蜜罐蚁腹特性（死亡回复）

蜜罐蚁腹拥有独特的死亡爆炸回复能力，牺牲自身为队友回血：

| 属性 | 说明 |
|------|------|
| 生命加成 | +40 |
| 速度 | -15 |
| 死亡效果 | 爆炸形成蜜液滩，回复范围内友军 |
| 回复量 | **50 HP** |
| 回复范围 | 80px |
| 蜜液动画 | 持续1秒的金色蜜液滩 |
| 成本 | 70食物 |

**机制说明**：
- 蜜罐蚁死亡时自动触发爆炸，无需冷却
- 80px 范围内所有友方蚂蚁各回复50生命值
- 爆炸形成金色蜜液滩动画（纯视觉，持续1秒）
- 被回复的蚂蚁身上出现金色回复粒子效果

**策略建议**：
- 适合作为前排牺牲品，死亡时为队友续航
- 配合高密度编队效果更佳，一次爆炸可回复多个友军
- 推荐配置：大齿猛蚁头 + 行军蚁胸 + 蜜罐蚁腹（冲前排+回复队友）
- 推荐配置：兵蚁头 + 切叶蚁胸 + 蜜罐蚁腹（坦克死亡后为队友续命）

### 木蚁腹特性（远程攻击 + 减速）

木蚁腹是唯一的远程攻击部件，具有以下特殊机制：

| 属性 | 说明 |
|------|------|
| 攻击方式 | 远程喷射酸液（椭圆形子弹） |
| 射程 | 150px（远超近战25px） |
| 生命惩罚 | -80% 最大生命值 |
| 基础伤害 | +5（直接加到远程伤害上） |
| 头部加成 | **享受完整的头部攻击力加成** |
| 胸部加成 | **享受完整的胸部攻击力加成** |
| 近战能力 | **无** - 木蚁腹蚂蚁只能远程攻击 |
| **减速效果** | 根据孵化室等级附加减速（见下表） |

#### 远程伤害公式

```
远程伤害 = max(1, 腹部伤害 + 头部伤害 + 胸部伤害)
```

> 即：远程单位享受完整的头部 + 胸部攻击力加成（不再是早期版本的 30%）。

#### 减速效果（根据孵化室等级）

| 等级 | 减速效果 | 持续时间 |
|------|----------|----------|
| 1级 | 无 | - |
| 2级 | **20%** 减速 | 3秒 |
| 3级 | **40%** 减速 | 3秒 |

**策略建议**：
- 配合高攻击力头部（如兵蚁头 +25 攻击 → 直接加成到远程伤害）
- 由于血量惩罚，需要前排近战单位保护
- 适合后排输出，远程消耗敌方单位
- **升级孵化室可获得减速效果**，3级孵化室的 40% 减速非常强力
- 远程子弹飞行速度 250px/s，命中检测半径 15px

### 大齿猛蚁头特性（弹射逃脱）

大齿猛蚁头是唯一拥有主动逃脱能力的部件，具有以下特殊机制：

| 属性 | 说明 |
|------|------|
| 攻击方式 | 近战攻击（+10攻击力） |
| 触发条件 | 生命值低于 40% |
| 逃脱效果 | 向己方基地方向弹射 150px |
| 恢复效果 | 恢复 50% 最大生命值 |
| 首次冷却 | **无冷却**（可立即触发） |
| 后续冷却 | 10秒 |

**策略建议**：
- 适合搭配高生命部件（蜜罐蚁腹），提升恢复量
- 弹射后脱离战斗，可以重新参与下一波战斗
- 多次存活能力使其在持久战中价值更高
- 前排坦克型配置：大齿猛蚁头 + 木蚁胸 + 蜜罐蚁腹

### 白蚁大兵头特性（攻速光环）

白蚁大兵头是团队增益型部件，每次攻击为周围队友提供攻速加成：

| 属性 | 说明 |
|------|------|
| 攻击力 | +5（基础伤害） |
| 光环半径 | 100px |
| 攻速上限 | **300%** |
| 自然衰减 | 每秒 -20% |
| 成本 | 100食物（高消耗） |

#### 攻速加成（根据孵化室等级）

| 等级 | 每次攻击加成 | 最大叠加 |
|------|-------------|----------|
| 1级 | +5% | 最高300% |
| 2级 | +10% | 最高300% |
| 3级 | +15% | 最高300% |

**机制说明**：
- 每次攻击为 100px 范围内所有友方单位（包括自己）增加攻速
- 攻速加成会自然衰减（每秒-20%），需要持续攻击维持
- 多只白蚁大兵头可以互相叠加效果，快速达到300%上限

**策略建议**：
- 适合集群配置，多只白蚁大兵头互相加速形成"攻速风暴"
- 高成本高回报，适合后期发力
- 配合高攻击力部件（兵蚁头+15攻击 → 白蚁大兵头+5 = +20总攻击）效果更佳
- 推荐配置：白蚁大兵头 + 行军蚁胸 + 织叶蚁腹

### 马塔贝勒蚁腹特性（尾针技能）

马塔贝勒蚁腹是高生命值的控制型部件，拥有强力尾针技能：

| 属性 | 说明 |
|------|------|
| 生命加成 | +80 |
| 技能类型 | 尾针攻击（近战触发） |
| 冷却时间 | 5秒 |
| 攻速减益 | **-50%** 攻速（持续4秒） |
| 攻速限制 | 最低 20%，最高 300% |
| 成本 | 110食物（高消耗） |

#### 中毒伤害（根据孵化室等级）

| 等级 | 中毒总伤害 | 持续时间 |
|------|-----------|----------|
| 1级 | 40 | 4秒 |
| 2级 | 60 | 4秒 |
| 3级 | 100 | 4秒 |

**策略建议**：

- 升级孵化室可大幅提升中毒伤害

### 切叶蚁胸特性（嘲讽+护甲）

切叶蚁胸是坦克型胸部部件，拥有主动嘲讽技能（低血量触发）：

| 属性 | 说明 |
|------|------|
| 生命加成 | +40 |
| 技能类型 | 嘲讽（低血量自动触发） |
| 触发条件 | 生命值低于 20% |
| 嘲讽范围 | 100px |
| 生命回复 | 30% 最大生命值 |
| 技能护甲 | **80%** 减伤（5秒） |
| 冷却时间 | 15秒 |
| 成本 | 90食物 |
| 攻速限制 | 最低 20%，最高 300% |

**机制说明**：

- 嘲讽迫使100px范围内所有敌人将攻击目标转向自身
- 同时回复30%最大生命值
- 嘲讽后获得5秒80%护甲，大幅减少受到的伤害

**策略建议**：
- 最强前排坦克，配合高生命部件可以承受大量伤害
- 嘲讽可以保护后方的远程单位（木蚁腹）
- 高护甲配合回复使其在5秒内几乎无敌
- 推荐配置：兵蚁头 + 切叶蚁胸 + 蜜罐蚁腹（极限坦克）
- 推荐配置：切叶蚁头 + 切叶蚁胸 + 马塔贝勒蚁腹（坦克+控制）

### 大头蚁头特性（秒杀）

大头蚁头是唯一拥有秒杀能力的部件，每次攻击有几率直接击杀敌人：

| 属性 | 说明 |
|------|------|
| 攻击力 | +5 |
| 生命值 | +40 |
| 攻速 | +100% |
| 秒杀动画 | 原地上下摇晃后甩飞消失 |
| 动画时长 | 1.2秒 |
| 成本 | 110食物（高消耗） |

#### 秒杀几率（根据孵化室等级）

| 等级 | 秒杀几率 |
|------|----------|
| 1级 | **3%** |
| 2级 | **5%** |
| 3级 | **8%** |

**机制说明**：
- 每次近战攻击按孵化室等级有 3%/5%/8% 几率触发秒杀
- 秒杀触发时，目标被举起、甩动、最终甩飞消失
- 秒杀动画期间目标无法被其他蚂蚁选为攻击目标
- 秒杀无视目标的护甲和当前血量，直接击杀

**策略建议**：
- **升级孵化室可提升秒杀几率**，3级8%秒杀非常强力
- 适合对付高生命值的坦克型敌人（如蜜罐蚁腹 + 切叶蚁胸）
- 攻速越快，秒杀触发概率越高（配合白蚁大兵头光环更佳）
- 推荐配置：大头蚁头 + 行军蚁胸 + 织叶蚁腹（高频攻击+秒杀）
- 推荐配置：大头蚁头 + 子弹蚁胸 + 陷阱蚁腹（极速攻击+秒杀爆发）

## Buff 系统

游戏内置了可扩展的 Buff 系统，允许蚂蚁的属性被临时影响。

### 支持的 Buff 类型

| Buff 类型 | 效果 | 来源 |
|-----------|------|------|
| `slow` | 降低移动速度 | 木蚁腹远程攻击（2-3级） |
| `poison` | 持续伤害（4秒） | 马塔贝勒蚁腹尾针技能、酸液场地 |
| `attackSpeedDown` | 降低攻击速度（4秒） | 马塔贝勒蚁腹尾针技能 |
| `armor` | 减少受到的伤害 | 切叶蚁胸嘲讽技能、子弹蚁胸肾上腺素 |
| `speedUp` | 提升移动速度 | 预留扩展 |
| `attackSpeedUp` | 提升攻击速度 | 白蚁大兵头攻速光环 |
| `damageUp` | 提升伤害 | 子弹蚁胸肾上腺素 |

### Buff 机制

- **持续时间**：每个 Buff 有固定持续时间，到期自动移除
- **叠加规则**：相同类型的不可叠加 Buff 会刷新持续时间并取更强效果；可叠加类型（如 attackSpeedUp）按层数累加
- **效果计算**：移速类 Buff 采用乘法计算（如 40% 减速 = 速度×0.6）
- **攻速上限**：最低 20%，最高 300%（防止数值极端化）

## 蚁后与 AI 系统

### 蚁后远程反击

双方蚁后会主动攻击进入 350px 范围的敌方蚂蚁：

- **攻击间隔**：0.5 秒（基础），可被"蚁后亢奋"实验降低
- **子弹伤害**：50
- **射程**：350px
- **子弹速度**：300px/s
- **视觉表现**：蓝方蓝色能量弹 / 红方红色能量弹，区别于木蚁腹的绿色酸液弹

### AI 决策模式

AI 默认按 `DefaultAIDecisionMaker` 调度，**每 ~1 秒** 执行一次决策。支持 3 种运行模式（由 LLM 战略顾问或本地启发式切换）：

| 模式 | 行为 |
|------|------|
| `upgrade_focus` | 升级优先：先升级已有孵化室，空位时才建造新孵化室 |
| `build_focus` | 扩张优先：先铺满所有空位孵化室，满了再升级 |
| `iterate` | 迭代替换：主动拆除弱单位孵化室，重建更强的（默认模式） |

### 难度等级

开局可在 三档难度 中选择，区别仅在敌方食物每周期加成：

| 难度 | 敌方食物加成 | 说明 |
|------|----------|------|
| 普通 | +0 | 公平对战 |
| 困难 | +6 | 敌方食物 +6 |
| 极限 | +12 | 敌方食物 +12 |

> 难度不影响 AI 决策模式 / 部件解锁节奏 / 实验公平性。

## LLM 战略顾问（可选）

游戏支持接入 **任意 OpenAI 兼容协议** 的 LLM 服务作为敌方 AI 的"战略顾问"，**非必需**（未配置时 AI 退化为本地启发式）。

### 作用

每 ~60 秒，LLM 会基于当前战场态势输出：

- **`mode`**：切换 AI 决策模式（upgrade_focus / build_focus / iterate）
- **`weights`**：各部件的偏好权重（影响建造选择）
- **`experiment`**：从白名单中选一个"实验性干预"（含 kind / side / magnitude / purpose）
- **`commentary`**：科学家风格的"实验记录"评语（左下角气泡）
- **`taunt`**：敌方蚁后的"冷峻发言"（右下角气泡）

### 支持的 Provider（UI 下拉选择）

| Provider | 默认 baseUrl | 默认 model | 备注 |
|----------|-------------|-----------|------|
| DeepSeek（深度求索） | `https://api.deepseek.com` | `deepseek-chat` | 国内直连 · 性价比高 |
| SiliconFlow（硅基流动） | `https://api.siliconflow.cn/v1` | `Qwen2.5-72B-Instruct` | 国内直连 · 多模型可选 |
| Moonshot（月之暗面 Kimi） | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` | 国内直连 · 长上下文 |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` | 需科学上网 |
| OpenRouter（统一网关） | `https://openrouter.ai/api/v1` | `deepseek/deepseek-chat` | 一站式接入多家模型 |
| Ollama（本地推理） | `http://localhost:11434/v1` | `qwen2.5:7b` | 本地推理 · 无需 key |
| 自定义（OpenAI 兼容） | 由用户填写 | 由用户填写 | 适用于任意 OpenAI 兼容服务 |

### 配置流程

1. 点击左上角 **🧠 AI 未启用** / **🤖 AI · Provider** 按钮
2. 选择服务商（Provider）、模型（Model）
3. 在 **API Key** 输入框中填入 key（密码模式输入，提交后立即清空输入框）
4. 点击 **💾 保存并启用** 或 **🧪 测试** 验证连通性
5. 顶部会出现绿色徽章 *🤖 AI 战略顾问：已启用 · {Provider}*

### 隐私与安全

- **API Key 仅保存在内存**（模块级 `llmKeyStore`），刷新即清空，**不写入** localStorage / Cookie / IndexedDB
- **不再从 `.env` 自动加载** —— Vite 会把 `VITE_*` 注入编译期 bundle，任何访问者都能在 DevTools 里看到，因此已禁用自动加载
- 输入框默认 `type="password"`，可点 👁 切换显示
- console 中只输出脱敏后的 mask（`sk-****abcd`）
- 可随时在设置面板中 **清除当前 Provider 的 Key**

### 无 LLM 时

未配置 API Key 时：
- AI 决策模式与权重由 `DefaultAIDecisionMaker` 自动选择（默认 `iterate`）
- "实验性干预"由 `OfflineScientist` 启发式生成（每 90s 一次，玩家血低时禁止对其施加负面实验）
- 不会输出 commentary / taunt（科学家保持沉默）
- 顶部横幅显示 **🧠 AI 未启用 · 点击配置** 黄色 CTA
