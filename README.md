# 蚁巢争霸 (Ant Colony Tug-of-War)

一款策略性拔河游戏，玩家通过建造孵化室、组装不同部件的蚂蚁来对抗 AI 敌人。

## 游戏玩法

### 核心机制
- **双方对抗**: 玩家（蓝方）在左侧，AI（红方）在右侧，各有一个蚁后基地
- **孵化室建造**: 在蚁后后方的建造区域放置孵化室，消耗食物
- **自动生产**: 每个孵化室定期孵化蚂蚁（初始10秒，每分钟+1秒，每室1只存活蚂蚁）
- **拔河战斗**: 蚂蚁自动向敌方基地前进，遭遇敌人时进行战斗
- **拔河优势**: 有单位越过中线时，每次食物生成额外+3
- **胜负条件**: 攻击对方蚁后使其血量归零即可获胜

### 资源系统
- **初始食物**: 0（从零开始积攒）
- **食物生成**: 每2秒双方各获得食物，初始5，每过1分钟+1
- **拔河优势**: 有己方单位越过中线时，每次食物额外+3
- **建造成本**: 基础30食物 + 部件成本
- **升级成本**: 等同于建造成本
- **拆除返还**: 50% 已投资资源

### 部件解锁系统
- **初始部件**: 双方各拥有基础三件套 + 随机1个阶段一部件（双方独立随机）
- **解锁频率**: 每过1分钟（游戏时间）双方各随机解锁一个部件
- **阶段限制**: 只能从已开放阶段中解锁，当前阶段全部解锁后需等待下一阶段开放

| 阶段 | 开放时间 | 可解锁部件 |
|------|---------|-----------|
| 阶段一 | 从开局起 | 火蚁头、木蚁胸、陷阱蚁腹、木蚁腹（共4个） |
| 阶段二 | 5分钟后 | 切叶蚁头、兵蚁头、行军蚁胸、子弹蚁胸、蜜罐蚁腹、织叶蚁腹（共6个） |
| 阶段三 | 10分钟后 | 大齿猛蚁头、白蚁大兵头、大头蚁头、切叶蚁胸、马塔贝勒蚁腹（共5个） |

## 孵化室系统

### 建造与管理

| 操作 | 说明 |
|------|------|
| 🏗️ 建造 | 点击空格，使用当前蚂蚁配置建造1级孵化室 |
| ⬆️ 升级 | 点击已有孵化室，花费建造成本升级 |
| 🗑️ 拆除 | 点击已有孵化室，拆除并返还50%资源 |

### 等级系统

| 等级 | 外观 | 属性加成 | 累计投资 |
|------|------|----------|----------|
| 1级 | 蓝色边框 | 基础属性 | 1x 成本 |
| 2级 | 金色边框 ★★ | +30% 攻击/生命（速度攻速不变） | 2x 成本 |
| 3级 | 紫色边框 ★★★ | +60% 攻击/生命（速度攻速不变） | 3x 成本 |

### 蚂蚁上限
- 每个孵化室最多同时拥有 **1只存活蚂蚁**
- 蚂蚁存活时，孵化室暂停生产
- 蚂蚁死亡后自动恢复孵化

## 战斗系统

### 蚂蚁行为状态

| 状态 | 行为 |
|------|------|
| **moving** | 向敌方基地前进，同时向中线靠拢 |
| **chasing** | 索敌范围(120px)内检测到敌人，追击目标 |
| **fighting** | 近战攻击范围(25px)内进入战斗，互相攻击 |
| **shooting** | 远程蚂蚁在射程(150px)内停止移动，发射酸液子弹 |

### 战斗特性
- **索敌追踪**: 蚂蚁会主动转向追击附近敌人
- **平滑旋转**: 蚂蚁身体朝向移动方向
- **2D战斗**: 蚂蚁在X/Y轴都会移动，形成自然战线
- **远程攻击**: 木蚁腹蚂蚁发射椭圆形酸液子弹，无法近战

## 蚂蚁部件系统

每只蚂蚁由 **头部、胸部、腹部** 三个部件组成，决定其属性。

蚂蚁部件分级，初始拥有基本三件套，敌人也一样，每过一分钟可以随机解锁一种蚂蚁部件，但是要到一定时间才能解锁下一阶段的部件，敌人和我方解锁部件独立
阶段一（从开头就能开始解锁）：火蚁头，木蚁胸，陷阱蚁腹，木蚁腹（如果解锁完了还没到五分钟就先不解锁了）
阶段二（游戏开始五分钟后才能开始解锁）：切叶蚁头，兵蚁头，行军蚁胸，子弹蚁胸，蜜罐蚁腹，织叶蚁腹
阶段三（游戏开始十分钟后才能开始解锁）：大齿猛蚁头，白蚁大兵头，大头蚁头，切叶蚁胸，马塔贝勒蚁腹

### 蜜罐蚁腹特性（死亡回复）

蜜罐蚁腹拥有独特的死亡爆炸回复能力，牺牲自身为队友回血：

| 属性 | 说明 |
|------|------|
| 生命加成 | +40 |
| 速度 | -15 |
| 死亡效果 | 爆炸形成蜜液滩，回复范围内友军 |
| 回复量 | **50 HP** |
| 回复范围 | 80px |
| 蜜液动画 | 持续1秒的金色蜜液滩 |
| 成本 | 35食物 |

**机制说明**：
- 蜜罐蚁死亡时自动触发爆炸，无需冷却
- 80px 范围内所有友方蚂蚁各回复50生命值
- 爆炸形成金色蜜液滩动画（纯视觉，持续1秒）
- 被回复的蚂蚁身上出现金色回复粒子效果

**策略建议**：
- 适合作为前排牺牲品，死亡时为队友续航
- 配合高密度编队效果更佳，一次爆炸可回复多个友军
- 推荐配置：大齿猛蚁头 + 行军蚁胸 + 蜜罐蚁腹（冲前排+回复队友）
- 推荐配置：兵蚁头 + 切叶蚁胸 + 蜜罐蚁腹（坦克死亡后为队友续命）

### 木蚁腹特性（远程攻击 + 减速）

木蚁腹是唯一的远程攻击部件，具有以下特殊机制：

| 属性 | 说明 |
|------|------|
| 攻击方式 | 远程喷射酸液（椭圆形子弹） |
| 射程 | 150px（远超近战25px） |
| 生命惩罚 | -30% 最大生命值 |
| 头部加成 | 头部攻击力的 30% 加成到远程伤害 |
| 近战能力 | **无** - 木蚁腹蚂蚁只能远程攻击 |
| **减速效果** | 根据孵化室等级附加减速（见下表） |

#### 减速效果（根据孵化室等级）

| 等级 | 减速效果 | 持续时间 |
|------|----------|----------|
| 1级 | 无 | - |
| 2级 | **20%** 减速 | 3秒 |
| 3级 | **40%** 减速 | 3秒 |

**策略建议**：
- 配合高攻击力头部（如兵蚁头 +25攻击 → +7.5远程伤害）
- 由于血量惩罚，需要前排近战单位保护
- 适合后排输出，远程消耗敌方单位
- **升级孵化室可获得减速效果**，3级孵化室的40%减速非常强力

### 大齿猛蚁头特性（弹射逃脱）

大齿猛蚁头是唯一拥有主动逃脱能力的部件，具有以下特殊机制：

| 属性 | 说明 |
|------|------|
| 攻击方式 | 近战攻击（+10攻击力） |
| 触发条件 | 生命值低于 40% |
| 逃脱效果 | 向己方基地方向弹射 150px |
| 恢复效果 | 恢复 50% 最大生命值 |
| 首次冷却 | **无冷却**（可立即触发） |

**策略建议**：
- 适合搭配高生命部件（蜜罐蚁腹），提升恢复量
- 弹射后脱离战斗，可以重新参与下一波战斗
- 多次存活能力使其在持久战中价值更高
- 前排坦克型配置：大齿猛蚁头 + 木蚁胸 + 蜜罐蚁腹

### 白蚁大兵头特性（攻速光环）

白蚁大兵头是团队增益型部件，每次攻击为周围队友提供攻速加成：

| 属性 | 说明 |
|------|------|
| 攻击力 | +5（基础伤害） |
| 光环半径 | 100px |
| 攻速上限 | **300%** |
| 自然衰减 | 每秒 -20% |
| 成本 | 50食物（高消耗） |

#### 攻速加成（根据孵化室等级）

| 等级 | 每次攻击加成 | 最大叠加 |
|------|-------------|----------|
| 1级 | +5% | 最高300% |
| 2级 | +10% | 最高300% |
| 3级 | +15% | 最高300% |

**机制说明**：
- 每次攻击为 100px 范围内所有友方单位（包括自己）增加攻速
- 攻速加成会自然衰减（每秒-20%），需要持续攻击维持
- 多只白蚁大兵头可以互相叠加效果，快速达到300%上限

**策略建议**：
- 适合集群配置，多只白蚁大兵头互相加速形成"攻速风暴"
- 高成本高回报，适合后期发力
- 配合高攻击力部件（兵蚁头+15攻击 → 白蚁大兵头+5 = +20总攻击）效果更佳
- 推荐配置：白蚁大兵头 + 行军蚁胸 + 织叶蚁腹

#### 中毒伤害（根据孵化室等级）

切叶蚁胸是坦克型胸部部件，拥有被动护甲和主动嘲讽技能：

| 属性 | 说明 |

- 同时回复40%最大生命值
- 嘲讽后获得5秒80%护甲，大幅减少受到的伤害

**策略建议**：

### 大头蚁头特性（秒杀）

大头蚁头是唯一拥有秒杀能力的部件，每次攻击有几率直接击杀敌人：

| 属性 | 说明 |
|------|------|
| 攻击力 | +5 |
| 秒杀动画 | 原地上下摇晃后甩飞消失 |
| 动画时长 | 1.2秒 |
| 成本 | 55食物（高消耗） |

#### 秒杀几率（根据孵化室等级）

| 等级 | 秒杀几率 |
|------|----------|
| 1级 | **3%** |
| 2级 | **5%** |
| 3级 | **8%** |

**机制说明**：
- 每次近战攻击有5%几率触发秒杀
- 秒杀触发时，目标被举起、甩动、最终甩飞消失

**策略建议**：
- **升级孵化室可提升秒杀几率**，3级8%秒杀非常强力
- 适合对付高生命值的坦克型敌人（如蜜罐蚁腹 + 切叶蚁胸）
- 攻速越快，秒杀触发概率越高（配合白蚁大兵头光环更佳）
- 推荐配置：大头蚁头 + 行军蚁胸 + 织叶蚁腹（高频攻击+秒杀）
- 推荐配置：大头蚁头 + 子弹蚁胸 + 陷阱蚁腹（极速攻击+秒杀爆发）

## Buff 系统

游戏内置了可扩展的 Buff 系统，允许蚂蚁的属性被临时影响。

### 支持的 Buff 类型

| Buff 类型 | 效果 | 来源 |
|-----------|------|------|
| `slow` | 降低移动速度 | 木蚁腹远程攻击（2-3级） |
| `poison` | 持续伤害 | 马塔贝勒蚁腹尾针技能 |
| `attackSpeedDown` | 降低攻击速度 | 马塔贝勒蚁腹尾针技能 |
| `armor` | 减少受到的伤害 | 切叶蚁胸嘲讽技能 |
| `speedUp` | 提升移动速度 | 预留扩展 |
| `attackSpeedUp` | 提升攻击速度 | 白蚁大兵头攻速光环 |
| `damageUp` | 提升伤害 | 预留扩展 |

### Buff 机制

- **持续时间**：每个 Buff 有固定持续时间，到期自动移除
- **叠加规则**：相同类型的不可叠加 Buff 会刷新持续时间并取更强效果
- **效果计算**：移速类 Buff 采用乘法计算（如40%减速 = 速度×0.6）

- **Tailwind CSS** - 原子化 CSS 框架
- **TypeScript** - 类型安全

### AI 决策系统

游戏内置了可扩展的 AI 决策系统，支持替换为自定义AI模型。

#### AI 决策接口

```typescript
import { 
  getGameEngine, 
  AIDecisionMaker, 
  AIBattleContext, 
  AIDecision 
} from './game';

// 自定义 AI 决策器
class MyLLMDecisionMaker implements AIDecisionMaker {
  makeDecision(context: AIBattleContext): AIDecision {
    // 分析战场态势
    const { enemyFood, enemyHatcheries, upgradableHatcheries } = context;
    
    // 返回决策
    return {
      action: 'upgrade', // 'build' | 'upgrade' | 'demolish' | 'wait'
      targetHatcheryId: upgradableHatcheries[0]?.id,
      reason: 'AI分析后决定升级',
    };
  }
}

// 替换 AI 决策器
const engine = getGameEngine();
engine.setAIDecisionMaker(new MyAIDecisionMaker());
```

#### AI 战场态势数据 (AIBattleContext)

| 字段 | 类型 | 说明 |
|------|------|------|
| `enemyFood` | number | AI 当前食物 |
| `playerFood` | number | 玩家当前食物 |
| `enemyQueenHp/MaxHp` | number | AI 蚁后血量 |
| `playerQueenHp/MaxHp` | number | 玩家蚁后血量 |
| `enemyHatcheries` | Hatchery[] | AI 孵化室列表 |
| `playerHatcheries` | Hatchery[] | 玩家孵化室列表 |
| `enemyAntsCount` | number | AI 存活蚂蚁数 |
| `playerAntsCount` | number | 玩家存活蚂蚁数 |
| `availableBuildPositions` | GridPosition[] | 可用建造位置 |
| `upgradableHatcheries` | Hatchery[] | 可升级的孵化室 |
| `gameTime` | number | 游戏时间 (ms) |

#### AI 手动操作接口

```typescript
const engine = getGameEngine();

// 手动建造
engine.aiBuildHatchery({ col: 0, row: 1 }, { head: 'soldier', thorax: 'army', abdomen: 'honeypot' });

// 手动升级
engine.aiUpgradeHatchery('hatchery-id-xxx');

// 手动拆除
engine.aiDemolishHatchery('hatchery-id-xxx');

// 获取战场态势（可用于 LLM prompt）
const context = engine.getBattleContext();
```
